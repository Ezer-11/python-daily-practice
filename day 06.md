
DAY 06 — PYTHON LOGIC PRACTICE (nested loops)

Q1. SUM OF DIGITS

Take an integer from the user and calculate the sum of its digits.

You must solve this without converting the number into a string.

Input:
5832

Output:
18

Explanation:
5 + 8 + 3 + 2 = 18


Q2. COUNT CHARACTER TYPES

Take a string and count:
- Uppercase letters
- Lowercase letters
- Digits
- Spaces

Input:
Hello Python 123

Output:
Uppercase: 2
Lowercase: 9
Digits: 3
Spaces: 2


Q3. FIND THE MISSING NUMBER

You are given a list containing n-1 distinct integers
from 1 to n.

Find the missing number.

Input:
5
1 2 4 5

Output:
3

Explanation:
The numbers should be 1, 2, 3, 4, 5.
Number 3 is missing

Requirement:
Try solving without sorting the list


Q4. REMOVE DUPLICATES FROM A LIST

Take a list of integers and remove duplicate elements
while preserving their original order.

Input:
8
2 3 2 5 3 7 5 9

Output:
2 3 5 7 9

Requirements:
- Do not use set().
- Preserve the original order.
- Try using loops and conditions.


Q5. FIND A PAIR WITH A GIVEN SUM

Take a list of integers and a target value.
Determine whether any two DIFFERENT positions in the
list contain numbers whose sum equals the target.

Input:
6
2 7 11 15 3 6
9

Output:
Pair found: 2 and 7

Another example:

Input:
4
1 2 4 8
20

Output:
No pair found

Requirements:
- Use nested loops.
- Do not use set() or dictionaries.
- Do not use the same element twice.
