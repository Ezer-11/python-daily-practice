Day 2 — Lists, Strings & Logical Conditions
Q1. Sum Elements at Even Indexes
- Take a list of integers.
- Calculate the sum of elements at indexes 0, 2, 4, 6, etc.
  
Q2. Count Numbers Divisible by 3 but Not 5
- Take multiple integers.
- Count numbers divisible by 3 but not divisible by 5.
  
Q3. Count Vowels
- Take a string as input.
- Count the vowels (a, e, i, o, u).
- Make the solution case-insensitive.
  
Q4. First Non-Repeating Character
- Take a string as input.
- Find the first character that appears exactly once.
- If no such character exists, report that.
  
Q5. Check Whether a List Is Sorted
- Take a list of integers.
- Check whether it is sorted in non-decreasing order.
- Do not use sort() or sorted().
- Equal adjacent elements are allowed.
