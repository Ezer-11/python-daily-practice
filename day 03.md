Day 3 — Indexing, Iteration & Problem Solving
Q1. Find First Occurrence Index
- Take a list and a target number.
- Find the index of its first occurrence.
- Do not use .index() or in for searching.
- Print -1 if the element is absent.

Q2. Count Descending Adjacent Pairs

- Given a list, count how many adjacent pairs satisfy:
a[i] > a[i+1].

Q3. Move Zeros to the End
- Take a list of integers.
- Move all zeros to the end.
- Preserve the relative order of non-zero elements.

Q4. Check Anagrams
- Take two strings.
- Check whether they are anagrams.
- Ignore spaces and uppercase/lowercase differences.
- Do not use sorting.

Q5. Longest Strictly Increasing Contiguous Sequence

- Find the length of the longest continuous sequence where each next element is strictly greater than the previous one.

Example:
a = [1, 2, 3, 2, 4, 5, 6, 1]

Expected output:
4

The longest sequence is [2, 4, 5, 6].
